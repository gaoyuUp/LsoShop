# 灵搜小店 · 代理分销系统（需求 + 实现细节 + 数据表设计）

> 本文档整合：用户原始需求、参考站（prodclub.ai /r/SMVVV9、prodclub.xyz/join）拆解、现有代码结构核对，以及一期落地方案。
> 开发前请通读，尤其「三、数据表设计」是开发依据，字段名以本文为准。

## 一、核心原则与角色模型

**网站根本不需要普通用户登录注册。** 代理是一类特殊身份，仅代理本人登录。

| 身份 | 入口 | 访问方式 | 登录 |
|---|---|---|---|
| 普通客户 | `/` | 不注册不登录，直接购买**系统价** | 无 |
| 代理客户 | `/r/:代理码` | 不登录也能购买，展示**该代理客户价**，订单归属代理 | 无 |
| 代理本人 | `/join` 开通 → 邮箱验证码登录 | 管理自己的价格、客户、订单、佣金、提现（「推广」后台） | 邮箱验证码（与管理员登录完全分离） |
| 管理员 | `/admin` | 现有管理员账号密码 | 用户名 + 密码（不变） |

**铁律：**
- 普通前台、订单页、导航中**不出现**任何「登录 / 注册 / 代理申请」按钮与文案。普通用户要觉得这是一个可以直接买的网站。
- 代理账号只用于代理本人。管理员账号与代理账号是两套独立体系、独立 Cookie、独立表。
- 代理链接**不悄悄归属**：无效/停用代理码 → 明确提示「链接无效」或回退系统价，不能把订单算给别的代理。
- 代理本人给自己（开通邮箱）购买时**不返佣**（order_type=self）。
- 同一客户账号邮箱**永久绑定首位**推广代理，后来用别人码不改绑。

## 二、各页面/模块改动清单（对应现有代码）

### 2.1 普通客户前台
| 位置 | 现状 | 要做 |
|---|---|---|
| 导航 `src/components/site/site-header.tsx` | 有禁用的「登录」按钮 + "登录注册即将开放" | **删除**登录按钮与文案 |
| 首页 `src/app/(shop)/page.tsx` | 分类筛选、商品卡（系统价）、购买说明、客服、「我的订单」入口 | 保留。`/` 下商品卡/详情**展示系统价** |
| 订单页 `src/app/(shop)/orders/page.tsx` + `orders-client.tsx` | 「本机订单」「查询订单」+ 残留「登录即将开放」「注册/登录」卡片 | **删除**登录/注册卡片及说明；保留本机订单、跨设备查询（订单号+口令 / 订单号+邮箱）、「去挑选商品」入口 |

### 2.2 代理价格店铺 `/r/:代理码`（新建，与首页同构）
- 复用首页 + 商品卡 + 详情 + 下单组件，**仅把可见价格替换为对应代理客户价**（含价位码）。
- `?src=渠道名` 记录渠道来源。
- 从代理链接进入后，切换分类 / 打开详情，**代理码与渠道值必须保留到提交订单**（通过 localStorage 存代理码+价位码+src）。
- 所有规格价格按代理价展示；库存、数量上限、交付方式、购买须知沿用规格配置。
- 订单保存：商品、规格、数量、**实际客户价、代理标识、src 渠道、价位码、成本价快照、系统价快照、佣金**。
- 价格口径要一致：列表显示代理价，详情结算也是代理价，不能结算恢复系统价。

### 2.3 代理开通与登录 `/join`（新建）
未登录参考站两栏布局：
- 左：开通表单（标题「开通账号」+说明、邀请码输入、邮箱输入、「发送验证码」、说明「每个邀请码只能开通一个账号」、已有账号→「代理登录」入口）。
- 右：代理卡片预览 + 「开通之后」说明（代理价、订单集中查看、邮箱验证码登录）。

业务规则：
- 管理员**必须先创建邀请码**，不能公开注册；邀请码格式参考 `YQUQ-RGM3-6SSK`。
- 每个邀请码只开通**一个**代理账号；用成功→标记已用并关联代理邮箱；错误/已用/停用/过期→对应错误提示。
- 邮箱验证码支持：过期、重发间隔、错误次数限制、发送频率限制。
- 已有代理可从 `/join` 切换「代理登录」（邮箱收验证码，**不要求普通客户登录**）。
- 代理登录后才显示代理身份标记与「推广」入口；未登录普通客户看不到。
- `/admin` 管理员登录与代理邮箱验证码登录**分离**。
- 邮箱验证码复用现有邮件服务（`src/lib/mail`），确认线上 SMTP 已启用；**验证码邮件与订单交付邮件区分模板/用途**。

### 2.4 代理工作区（登录后「推广」后台，新建 7 菜单）
布局沿用参考站：左侧固定推广菜单（推广码卡片、7 个菜单、底部今日/本月佣金），右侧为当前菜单内容。深色卡片、圆角分区、分段筛选、明确主按钮；动画只用于状态切换与数据刷新，避免整页闪动。
**代理只能读改自己的推广资料/价格/客户/订单/佣金/提现；后端接口必须校验代理身份，不能只靠隐藏菜单。**

7 菜单：概览、订单、排行榜、客户价、客户、提现、联系方式。逐菜单要求见 2.5。

### 2.5 七个菜单细节
**① 概览（自上而下）**
- 开张三步卡（横 3 张）：设置客服联系方式 / 发出推广海报或链接 / 拿到第一笔佣金；显示状态与进度；拿到第一笔佣金后整卡自动收起；**推广海报按钮一期禁用**。
- 4 张佣金/客户卡：今日佣金及订单数、昨日佣金、本月佣金及订单数、可结算佣金及返佣单数、绑定中客户数及累计客户数。**勿重复统计**已结算/可提现/提现申请中金额。
- 待打款卡：待打款或可申请金额、申请提现按钮、最低 ¥50 门槛、人工转账说明；金额不足/已有未处理申请/账号异常时按钮禁用并说明。
- 我的推广码卡：左侧平台 Logo+推广码+二维码；右侧用途说明 + 5 按钮（复制推广链接、复制推广码、推广海报[禁用]、二维码、复制推广文案）。二维码指向 `/r/:代理码`；分享链接支持 `?src=wechat`。
- 推广规则折叠卡（默认折叠）：利润 100% 返佣、老客户回购仍归绑定代理、先绑定优先、自购不返佣。
- 推广效果区：说明 + 今天/7天/30天/90天切换；4 指标卡（访客、链接打开、下单、付款、付款转化率）；趋势图（访客/打开/下单/付款 4 线 + 图例）；图下按日期 4 项数据表；底部渠道来源 + 推广码/价位码分码统计。

**② 订单**
- 顶部统计：成交、GPT 成交、销售额、累计佣金 + 本月数据 + 商品成交分布。
- 筛选行：左侧切「客户的单 / 我下的单」；右侧时间筛选 + 导出。
- 下方按日期分组订单行；行内突出商品名/规格/数量/金额/时间/状态。
- 客户订单显示推广归属 + 佣金状态；代理自购标记「自购、不计推广佣金」。点订单→详情（支付/交付状态 + 商品快照）。
- 无客户推广订单时显示空状态，说明「客户用推广码下单且完成开通后会显示在此」。

**③ 排行榜**
- 上方左侧商品筛选，右侧独立「销售额/单数」+「今日/本周/本月/全部」。
- 中间前三名领奖台（2 名在左、1 名居中、3 名在右），头像/代理名/指标。
- 领奖台下「你的位置」卡，再下第 4 名起列表（代理名、商品成交明细、销售额/单数）。
- 点商品只更新该商品榜单（不跳菜单），标签选中视觉反馈 + 轻量过渡。
- 商品筛选**动态**由后台在售商品生成（不写死 Plus/Pro5x/接码）；商品多时筛选条一行（桌面横滚或「更多商品」下拉，移动端选择器），列表分页/加载更多；前 3 + 你的位置区保持视觉稳定。
- 排名口径：完成且符合返佣条件的客户推广订单，自购排除；多规格按商品汇总，规格可在明细展开。

**④ 客户价**
- 顶部显示商品分类（按后台分类排序）；点分类→只显示该分类在售商品。
- 每个商品可折叠；展开按规格显示代理可设置的客户价。
- 每规格显示：系统公开价、代理成本/最低价、当前代理客户价、预计佣金。
- 价格输入框（可加滑块，但输入框必须能精确输入金额）。保存后立即应用到代理链接与详情；未保存修改要有状态提醒。
- 分类/商品增加自动更新；商品下架后不能新下单，但历史订单价格快照保留。
- 统一价格边界：管理员为每个可售规格维护代理成本/最低价，代理设客户售价；页面按「客户售价 − 代理成本」预估佣金；售价允许范围要明确（不让代理误设低于成本价）；未设置代理价→默认用系统公开价并标注「默认价」。

**价位码**（主价格表下单独卡片）
- 标题/用途说明 +「生成价位码」按钮；每个价位码对应独立客户价表，可发给不同客群；未配置价格的商品沿用代理主价格。
- 显示：名称、码值、分享链接、编辑价格、复制链接、停用入口。价位码带来的佣金仍归代理。
- 概览统计出现价位码、价格页显示没有价位码 → **页面数据不一致**，本站要让价位码列表/二维码/链接/推广统计读**同一数据源**。一期开放价位码。

**⑤ 客户**
- 顶部切「快到期 / 全部客户」。
- 标题+说明下：搜索框、搜索按钮、状态筛选（全部/回头客/会员已到期/绑定中/已过期/已结束）。
- 列表：打码后的开通账号、备注、绑定时间、会员状态、相关购买信息；代理可编辑备注。
- 无客户时「还没有绑定的客户」，说明首次用推广码下单并完成开通才绑定。
- **绑定关系与会员状态分开**：会员到期 ≠ 推广关系解除。
- 同一开通账号只绑定一位代理，首次绑定成功永久归属，后来用别人码不能改绑。

**⑥ 提现**
- 顶部卡：可提现金额、最低 ¥50 门槛、申请按钮。
- 申请填：提现金额、支付宝账号、收款人姓名；金额不得超过可提现余额；提交后金额锁定，避免重复申请。
- 下方「提现与打款」按一笔一行：申请金额、申请时间、收款账号尾号、状态、处理时间。
- 待审核允许代理撤回；后台已处理不可撤回。
- 主后台人工支付宝转账后标记已打款，记录时间与备注；可加拒绝状态与拒绝原因。

**⑦ 联系方式**
- 主区域中间「我的客服联系方式」表单，右侧「买家看到的」实时预览。
- 微信号/微信二维码/QQ/Telegram 均可单独选填；二维码支持 JPG/PNG，限制大小，提示「上传后会展示给买家」。
- 保存后立即更新代理链接买家看到的联系方式；全空时显示「联系推荐人」提示。
- **代理客服与主后台站点客服分开存储**：代理链接显示代理客服，根路径显示平台客服。

### 2.6 主后台 `/admin` 改动（保留现有结构）
现有：总览、商品、分类、库存、订单、邮件、设置。新增「代理管理」并扩展商品/订单。

**总览**增加代理运营卡：有效代理数、待处理提现申请数与金额、累计推广成交额、已结算/待结算佣金、代理推广订单数、最新提现申请、最新推广订单。保留现有商品销售/库存水位/最近订单。

**新增「代理管理」模块**
- 代理列表：邮箱、推广码、状态、开通时间、绑定客户数、推广订单数、推广销售额、待提现余额；搜索/查看详情/启用暂停。
- 邀请码管理：码值、状态（未使用/已使用/已停用/已过期）、创建时间、使用邮箱、关联代理、备注、有效期；创建、复制开通链接、停用未使用邀请码。开通链接可带预填邀请码，但**不能因此允许任意注册**。
- 代理详情：基本资料、推广码、客户价、客户、订单、佣金记录、提现记录；可停用代理、重置/撤销未使用邀请码，**不能修改已完成订单的历史佣金快照**。
- 提现管理：按待处理/已打款/已拒绝筛选；显示代理邮箱、申请金额、收款人、支付宝账号、申请时间、备注；转账后管理员手动标记已打款并记录时间；不接支付宝自动转账。

**商品/规格编辑增加代理价格字段**（规格级）
- 是否参与代理销售
- 代理成本价/佣金计算基准价
- 代理客户价可设最低/最高价（或全局规则约束）
- 未设代理价时的默认规则
- 价格**按规格**保存；主后台保留系统公开价，不被任一代理改价覆盖。

**订单管理扩展推广信息**
- 订单类型：普通客户 / 自购 / 代理推广客户
- 推广代理与推广码、渠道来源 src
- 下单时商品规格、系统价、代理客户价、成本价快照
- 佣金金额、佣金状态（待结算/可提现/已提现/已撤销）
- 开通账号邮箱 + 客户绑定状态
- 订单详情要能解释这笔佣金怎么算的；退款/关闭/未开通成功时按规则撤销或不结算佣金。

**设置页增加「推广设置」区**
- 最低提现金额（默认 ¥50）、佣金比例（当前 100%）、客户绑定规则与自购排除规则、代理价格范围/默认价策略、邀请码默认有效期（可选）、未来币种/支付方式扩展字段（一期只启用人民币，不展示未启用 USDT）。
- 平台客服仍由现有「站点内容」管理；代理客服由代理后台管理。

## 三、数据表设计（MySQL，Drizzle 生成）

> 命名沿用现有风格：snake_case 表名，`created_at/updated_at` 统一 `datetime(3)` UTC。

## 四、业务口径（开发必须遵守）

| 项 | 规则 |
|---|---|
| 代理客户价范围 | 该规格**当前售价 ~ 划线原价**；无划线原价则最高=当前价 |
| 佣金 | 每单利润 100% 返佣；佣金 =（客户实付 − 系统价）× 数量 × 比例；自购=0 |
| 佣金结算 | 自动发货→付款成功即结算；需开通会员→开通完成(发货)才结算 |
| 客户邮箱 | 收件邮箱选填/必填沿用商品配置；不新增 ChatGPT 字段；开通账号如何关联后续设计 |
| 客户绑定 | 首绑永久；会员到期不改绑；重复下单仍归绑定代理 |
| 提现 | 一代理同时仅一笔 pending；提交后锁定金额；¥50 起；人工支付宝转账 |
| 价位码 | 一期开放；独立价格表；未配置商品沿用主价；佣金仍归代理；与概览/价格页读同一数据源 |
| 一期币种 | 仅人民币；保留未来 USDT/支付方式扩展字段，不展示未启用项 |
| 代理链接 | `/r/:code`、`/r/:code?pc=价位码`、`?src=渠道`；无效/停用→提示或回退系统价，不悄悄归属 |
| 自购识别 | 下单代理码 == 登录代理本人，或客户邮箱 == 代理开通邮箱 → order_type=self，不返佣 |

## 五、一期实现范围（主流程）
1. 普通客户免登录购买 + 订单查询；删除公开登录/注册入口。
2. `/r/:代理码` 代理价店铺 + 推广归因（含价位码、src、访客统计）。
3. `/join` 邀请码开通 + 代理邮箱验证码登录。
4. 代理「推广」后台 7 菜单（海报按钮禁用）。
5. 按商品分类+规格设代理客户价。
6. 订单推广归属、客户绑定、佣金结算、客户列表。
7. ¥50 起提 + 支付宝人工打款 + 主后台提现管理。
8. 主后台：邀请码管理、代理管理、商品代理成本价、订单推广字段。
9. 一期仅人民币；保留币种/支付方式扩展字段。

整体：代理简洁、模块清晰、页面速度最佳模式。
